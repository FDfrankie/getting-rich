| **台灣本土合規出入金** | **MAX (MaiCoin集團)** / **BitoPro (幣託)** | 支援台灣銀行法幣帳戶直接綁定，新台幣 (TWD) 1:1 轉帳出入金，通過台灣金管會洗錢防制法令遵循聲明。 |
| **國際頂級流動性與衍生品** | **Binance (幣安)** | 全球交易量龍頭，深度最厚、滑價最小、API 最穩定，手續費低（Maker 0.02% ~ 0.04%）。 |
| **專業量化與合約首選** | **OKX (歐易)** / **Bybit** | API 頻率限制寬鬆，支援多資產統一帳戶模式 (Unified Margin)，策略回測與高頻執行極佳。 |

## 2. 註冊與身份驗證 (KYC)

所有正規交易所均要求 **KYC (Know Your Customer)** 實名認證，以符合國際反洗錢規章：

1. **基本註冊**：使用安全性高的專用 Email（如 Google 帳戶並開啟 Titan/硬體 2FA）。
2. **Lv.1 / Lv.2 身份審核**：
   - 上傳身分證正反面照片（台灣用戶）或護照。
   - 人臉活體辨識（手機鏡頭點頭/眨眼）。
3. **台灣法幣銀行帳號審核（以 MAX 為例）**：
   - 需綁定本人同名之台灣實體銀行帳戶（如中信、國泰、玉山等）。
   - 審核通過後，僅允許從該指定銀行帳號轉入資金，任何非本人或未綁定帳號轉帳將被原路退回。

## 3. 出入金管道全攻略 (台幣 ↔ USDT)

### 管道 A：台灣合規交易所網銀電匯（最推薦、最安全）
1. 進入 MAX / BitoPro 後台，點擊 **「TWD 入金」**，獲取專屬遠東/凱基虛擬帳號。
2. 使用您已綁定的網銀 App 進行轉帳（通常 5~15 分鐘到帳）。
3. 進入交易大廳，在 `USDT/TWD` 市場掛限價單或市價單買入 USDT。
4. 點擊 **「提領 USDT」**，網絡選擇 **TRON (TRC20)** 或 **Arbitrum One / BNB Smart Chain**（手續費約 1~2 USDT），將地址填為您的幣安/OKX 儲值地址。

### 管道 B：交易所 C2C / P2P 買幣（注意防詐要訣）
- **操作方式**：在幣安/OKX 平台上的 C2C 專區，向有認證的廣告方以街口支付、LINE Pay 或網銀轉帳直接購買 USDT。
- ⚠️ **防詐騙鐵律**：
  1. **堅持平台內交易**：絕對不要聽信對方引導加入 LINE 或 Telegram 進行「線下場外交易」。
  2. **務必確認收款方與平台實名完全一致**：若賣家提供的銀行帳號戶名與平台驗證姓名不同，**立即取消交易並向官方客服檢舉**，避免捲入第三方洗錢凍結帳戶（三方詐騙）。
  3. **未確認收到銀行入款通知前，絕不點擊「放幣」按鈕**。

## 4. 現貨 vs 永續合約 (交易機制本質)

量化交易程式最常涉足的兩種市場：

### (1) 現貨交易 (Spot)
- **概念**：一手交錢，一手交貨。你用 1,000 USDT 買入 0.015 BTC，你真正擁有了這 0.015 顆比特幣。
- **風險**：無爆倉清算風險（只要幣種不歸零），但只能**「做多 (Long)」**，無法在下跌波段放空獲利。
- **費用**：僅買賣單次手續費（通常 0.075% ~ 0.1%）。

### (2) 永續合約 (Perpetual Futures)
- **概念**：不發生現貨交割的衍生品合約，以保證金交易。
- **雙向交易**：既能**看漲做多 (Long)**，也能**看跌做空 (Short)**。
- **槓桿機制**：可用 2x ~ 100x 槓桿。**量化策略強烈建議槓桿不超過 1x ~ 3x**，避免突發插針引發強制平倉 (Liquidation)。
- **資金費率 (Funding Rate)**：
  - 為使合約價格錨定現貨價格，每 8 小時在多空雙方之間結算一次資金費用。
  - 當多頭狂熱時，資金費率為正（多方支付費用給空方）；反之空方付費給多方。此機制亦可發展出**期現套利 (Funding Arbitrage)**。

## 5. API Key 申請與軍規安全防護指南

當您準備讓 Python 量化程式託管下單時，API Key 的安全性等同於您的金庫密碼！

### 幣安 API Key 申請步驟：
1. 登入幣安官網 ➔ 右上角頭像 ➔ 點選 **【API 管理 (API Management)】**。
2. 點選 **「建立 API」**，選擇系統生成（HMAC）。
3. 進行信箱與 2FA 二階段驗證碼確認。
4. 記錄下系統顯示的 `API Key` 與 `Secret Key`（**Secret Key 僅會完整顯示一次，請妥善存於加密密碼庫**）。

### 🛡️ 軍規安全配置三原則（極其重要）：
1. **🚫 絕對關閉「允許提現 (Enable Withdrawals)」權限**：
   - 99.9% 的量化交易只需要開啟 **「讀取 (Read)」** 與 **「允許現貨及槓桿交易 / 允許合約交易」**。
   - **永不勾選提幣權限**！即使 API Key 不慎外洩，駭客也完全無法把您的任何一分錢轉走。
2. **🔒 綁定固定 IP 白名單 (IP Whitelist)**：
   - 在 API 權限設定中勾選「僅限受信任 IP 訪問」。
   - 填寫您的固定 VPS 伺服器 IP。未在白名單內的任何來源請求，幣安伺服器一律拒絕。
3. **🔑 嚴禁將 API Key 寫死在程式碼或推送到 GitHub**：
   - 必須使用 `.env` 檔案載入，並在 `.gitignore` 中加入 `.env`。
