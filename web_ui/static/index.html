CLOUD RUNNING & MOBILITY

隨時隨地用手機操作：脫離本機全天候執行方案

本專案已完整容器化 (Dockerized)，您有多種免費且免開電腦的雲端部署途徑，手機打開瀏覽器即可監控。

1. 免費雲端伺服器 (Render / Railway)

將此專案推送到您的 GitHub 私人庫，在 Render.com 或 Railway.app 點選 New Web Service，它會自動識別專案內的 Dockerfile 部署上線！

優點：24 小時不間斷執行，提供免費 HTTPS 網址，手機可直接書籤加到主畫面。
2. Kaggle 雲端免費 GPU 算力

專案已在 kaggle_notebooks/ 備妥兩個現成 Notebook。利用 Kaggle 的免費 P100/T4 GPU 進行大規模 ML 特徵工程與 RL 強化學習訓練。

優點：完全不吃本機 CPU，每週提供 30 小時免費雙 GPU 算力！
3. Cloudflare Tunnel 免費公網穿透

若本機電腦開著，只需一行指令 cloudflared tunnel --url http://localhost:8000，立即產出一個安全的公網 URL，在外用 iPhone/Android 隨處可連！

優點：零設定防火牆、零固定 IP 需求，極致安全無延遲。

  • ✅ docker-compose.yml - 本地或 VPS 一鍵啟動指令

LIVE TRADING GUIDE

真實虛擬貨幣交易所實戰操作手冊

從台幣出入金、KYC 實名、合約機制到 API 安全防護完整教學。詳細文檔亦存於 crypto_trading/real_exchange_trading_guide.md。

一、台幣入金黃金路徑 (最合規且零手續費)

1. 註冊台灣通過洗錢防制規範的本土交易所：MAX (MaiCoin) 或 BitoPro。

2. 完成 Lv.2 身分認證並綁定個人台幣銀行帳戶。

3. 網銀轉帳新台幣至 MAX 專屬帳號，並在交易大廳以現貨市價換取 USDT (泰達幣)。

4. 點選「提領 USDT」，透過 TRC20 或 Arbitrum 網絡將 USDT 轉入您的 幣安 (Binance) 帳戶。

二、現貨 (Spot) vs 永續合約 (Futures) 核心區別

• 現貨：買入即真實持有，無爆倉歸零風險，但僅能做多（無法在空頭暴跌時獲利）。手續費通常約 0.08%。

• 永續合約：以保證金交易，多空皆可雙向操作，支援 1x~50x 槓桿。量化程式常跑合約以獲取做空保護，但建議實盤槓桿壓低在 1x~2x 內避免黑天鵝極端行情穿倉。

三、API Key 軍規安全三大防線 (切記！)

1. 🚫 永遠不要勾選「提現 (Withdrawal)」權限：量化交易只需「行情讀取」與「現貨/合約交易」權限。只要關閉提現，任何人都偷不走您的錢！

2. 🔒 綁定固定 IP 白名單：設定只有您部署的 VPS/伺服器 IP 可以呼叫下單。

3. 🔑 絕不外洩 Secret Key：金鑰請放入 .env 本地檔案，切勿上傳至 GitHub 等公開場所。
